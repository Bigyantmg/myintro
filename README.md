# My Philosophical World
Plain HTML/CSS/JS. No build step, no dependencies (only Google Fonts).

## Structure
- `index.html` – page structure and SEO tags
- `js/data.js` – **edit this**: name, bio, photo, questions, content, books, posts, timeline, social links, email
- `js/main.js` – behaviour (intro, cursor, reveals, filters)
- `css/styles.css` – design (colors in `:root`)
- `images/` – put your photo and thumbnails here
- `robots.txt`, `sitemap.xml` – replace `example.com` with your domain

## Run locally
Open `index.html` in a browser, or in VS Code use the Live Server extension.

## Deploy free
Push the folder to a GitHub repository, then enable GitHub Pages (Settings → Pages → main branch), or drag the folder into Netlify/Cloudflare Pages.

## Placeholders to replace
Your name (also in `index.html` title/meta), photo, email, social URLs, content links, articles. Empty URLs show "link coming soon" instead of broken links.
The newsletter and contact forms are visual placeholders and send nothing. Connect a service (Formspree, Buttondown, etc.) when ready.
